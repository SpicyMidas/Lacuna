# Hand-drawn textures

Files in this folder are drawn by hand and copied **byte for byte** over the generated textures by
`tools/gen_textures.py` (after every art module has run). Paths mirror `assets/lacuna/textures/`.
Never re-encode, resize or regenerate them; to replace one, drop the new PNG (and its `.mcmeta`, if animated)
at the same path.

`item/chronoshard_pocket_watch.png` (576 frames) has no `.mcmeta` here on purpose: its frame list is generated by
`tools/art/m16_pocket_watch_frames.py`. Every frame of the strip is correct, but the exporter named them 00..575 and
stacked them in text order (00, 01, ..., 09, 10, 100, 101, ..., 109, 11, 110, ...), so every 11th frame came from a much
earlier moment and runs of ten sat far from their place. The earlier hand-made frame lists only cut and skipped parts
of that scrambled strip, so the slow hand kept jumping (from bottom right back to the top, then on to the left). The
module splits each frame into the face (per-pixel mode of the strip), the bright fast hand and the darker slow hand,
checks that the strip's true order moves the fast hand one of its 24 drawn steps every frame and the slow hand one step
every 12 frames, never back, with the loop closing on the first frame (the gem's blue, purple, black, red fade runs once
over the 576 frames), and writes the frame list that plays it. The PNG itself is untouched; do not add a `.mcmeta` for
it here (a hand-made one would override the generated order).
